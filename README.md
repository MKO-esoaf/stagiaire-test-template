# Projet Stagiaire

Instructions générales du projet.
## Structure

- backend-dotnet : API REST en .NET
- frontend-flutter : Application Flutter
- postman : Collection d'exemples d'appels API

## Lancement rapide

1. Lancer le backend (voir backend-dotnet/README.md)
2. Lancer le frontend (voir frontend-flutter/README.md)
3. Tester les endpoints avec Postman (voir postman/collection.json)
